What each test proves:
  A. test_configured_checkpoint_wins_over_newer_file - two fake checkpoints
     with different mtimes; B is 9999 s newer; the resolver still returns A
     because resolution reads the configured path only.
  B. test_missing_checkpoint_fails_loudly - a nonexistent configured
     checkpoint raises FileNotFoundError (Configured checkpoint does not
     exist). No silent fallback, no newest-file discovery.
  C. test_sha256_deterministic - sha256_file() returns an identical digest
     on repeated calls and matches hashlib.sha256 of the exact bytes.
  D. test_app_and_cli_share_checkpoint_identity - app._get_model() and
     predict._resolve_model_path(None) resolve the same absolute path and
     identical sha256/size identity.
  E. test_no_mtime_checkpoint_discovery_anywhere - inspect.getsource of
     resolve_checkpoint contains no "glob"/"st_mtime" tokens; app.py,
     predict.py and scripts/validate_external.py contain no "st_mtime"
     and no ".glob(" - a regression to newest-by-mtime selection fails CI.
