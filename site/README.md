# BrainVuln — Live Results Site

A static, zero-dependency dashboard rendered **directly from the frozen
evaluation artifacts** — no build step, deployed on Vercel.

## What it shows

* Held-out test performance (canonical seed 42, n=27 subjects) with
  subject-bootstrap 95% CIs
* Multi-seed robustness distribution (seeds 42, 1, 2, 3, 4) — mean ± SD,
  median [IQR], min–max, per-seed table
* Prediction / error stability and the seed-4 reproducibility result
* Confounding (age association) and calibration findings
* Grad-CAM coverage and regional-stability summary
* The four real evaluation plots (ROC, PR, confusion matrix, calibration)

Every number is generated by `scripts/make_site.py` from
`results/ml/evaluation/`, `results/ml/multiseed/` and
`audit_artifacts/` — nothing is hand-copied. Research use only; the page
carries the mandated research-only banner.

## Regenerating after new artifacts

```bash
.venv/Scripts/python.exe scripts/make_site.py   # rebuilds site/
git add site && git commit -m "Refresh results site" && git push
```

Vercel (and any static host) picks the committed `site/` folder up
automatically — no build configuration needed (`vercel.json` sets
`outputDirectory: "site"`).
